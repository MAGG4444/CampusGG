# Game artwork inventory

Reviewed 2026-11-15 for use as a game-channel identifier on CampusGG, a public multi-game forum. An official source, a trademark, or a press download alone does not establish permission for this particular use. This inventory is not a legal determination: an applicable license, permission, or legal exception may exist even where it has not been verified here. Conditions and policies can change.

**Deployment status:** no publisher artwork is currently mapped. The original-color Overwatch and Rocket League files previously mapped are retained in the ignored local preview directory but disabled in production until their applicable conditions or another authorization are verified. All channels use the neutral `ChannelLogo` fallback in production. Vite's production build does not copy the public directory. This avoids assuming CampusGG's commercial status, any existing publisher agreement, or satisfaction of required notices. The images linked below are candidates, not runtime hotlinks or a representation that their use is prohibited.

## Local-only preview

The ignored `campusgg-frontend/local-game-art/` directory is served only by the Vite development server when `VITE_CHANNEL_LOGO_PREVIEW=1`. From PowerShell in `campusgg-frontend`, run `$env:VITE_CHANNEL_LOGO_PREVIEW='1'; npm run dev`, then use the ordinary Forum pages. Remove the variable and restart Vite to turn the preview off. Do not expose this server publicly. The preview is not a grant of permission.

Place the unmodified candidate files in that directory using the following names: `valorant.png` (choose a color PNG from Riot's linked pack), `league-of-legends.png`, `counter-strike-2.jpg`, `dota.jpg`, `minecraft.jpg`, `it-takes-two.webp` (the linked Hazelight URL requests WebP), `overwatch-2.svg`, and `rocket-league.svg`. The last two were already present locally; the other six were not downloaded because network access failed during this review. Missing images use the normal fallback. These local files are ignored by Git and are outside Vite's public directory and build output. The original local fan files are also retained there, unused.

## Other local files

The unused monochrome `valorant.svg`, `lol.svg`, `cs2.svg`, `dota2.svg`, and `minecraft.svg` came from the third-party [games-icons collection](https://github.com/klimentsii/games-icons/tree/main/icons); its fan-art provenance and monochrome appearance make them unsuitable for this request. The unused `it-takes-two.png` is a [third-party fan icon](https://icon-icons.com/icon/it-takes-two-logo/249696), credited there to MurkyyLurkss; the artwork's publisher rights remain separate. These files are retained in the ignored local directory to avoid deleting existing working-tree work and are not referenced by the UI.

When a candidate is cleared, add an appropriately sized local file, record the precise source, license/permission and conditions here, and add its filename to the existing `channelPresentation` entry. `ChannelLogo` then supplies it consistently to Forum surfaces and falls back on load failure.
